Обсерватория **Ton Raffles Token (RAFF)** в сети TON. Создана из чистого
[TON-Observatory-Template](https://github.com/Freebielife/TON-Observatory-Template),

## О проекте

По самоописанию проекта, RAFF — утилитарный токен экосистемы tonraffles.app.
Официальный канал описывает инструменты запуска токенов и NFT, стейкинга,
блокировки активов и массовых переводов. Это описание назначения по заявлениям
проекта, без независимой проверки работы этих сервисов.

## Функции и границы данных

- RU/EN, график оценки капитализации в TON/USD, покупки, продажи и сжигания.
- Сбор операций из трёх подтверждённых RAFF/TON-пулов STON.fi и DeDust;
  адреса и ссылки на доказательства обменов находятся в project.json.
- Другие индексируемые пары показаны отдельно; их сделки не объявляются
  полностью охваченными общей лентой.
- Топ-10 держателей с раскрытием до топ-20; сервисы и контракты отдельно.
- Справочник сервисов Tonkeeper с источниками; общие OG, +888, четыре цифры
  .ton и метка сжигания. Проверка NFT/DNS и идентичностей идёт постепенно.
- История догружается по частям. Отсутствующие интервалы остаются неполными;
  при сбое сохраняется последний исправный снимок.
- Капитализация — оценка по последнему обмену основного пула и **текущей полной
  эмиссии**, без заявления о circulating market cap.
- Заморозка и стейкинг RAFF не подключены: вместо неподтверждённых цифр — прочерки.

## Оформление

Предоставленное владельцем изображение RAFF встроено отдельно как логотип и
флаг разделов. Метаданные ссылаются на jetton.svg, но прямое скачивание SVG и
его кэша вернуло HTTP 403 в рабочей среде; использован предоставленный файл.
Ресурсы интерфейса (JS/CSS/изображения) встроены в **index.html**.
Обновление данных и ручной поиск кошельков требуют сети.

## Сборка и обновления

```sh
python3 -m scripts.refresh_observatory
python3 build.py
python3 verify.py
python3 -m unittest discover -s tests -p 'test_*.py'
node --test tests/*.test.cjs
```

GitHub Actions: `.github/workflows/update.yml`, ручной запуск, изменения кода и
резервное расписание **17 и 47 минут каждого часа UTC**. Расписание — запрос
запуска со стороны GitHub; задержки платформы возможны.

Снимок загружается из этого репозитория, с резервным GitHub API и защитой от
подмены более старыми/неполными данными. `docs/cloudflare-registration.mjs`
содержит запись для добавления в полный действующий реестр общего
Cloudflare-планировщика. Подключение к нему не подтверждено; рабочий реестр
и существующие сайты не изменялись.

Публикация в TON Storage / Resistance Tools — отдельный шаг. Готовый к загрузке
файл: **index.html**. Статус проведённых проверок — `docs/QA.md`.

Локальная поправка RAFF к версии 1.3.0: суточная сумма сжиганий читает
поле `tokenAmount` из снимка. Остальные обсерватории не изменялись.
